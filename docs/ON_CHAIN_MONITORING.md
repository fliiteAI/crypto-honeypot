# On-Chain Monitoring Guide

On-chain monitoring is the final layer of detection (Layer 4). It tracks whether an attacker has successfully imported stolen keys and is attempting to move funds or query balances on the public blockchain.

## Exporting Public Addresses

To monitor your honeypots on-chain, you first need to export the public addresses generated by the `honeypot-deployer`.

```bash
honeypot-deployer export-addresses \
  --manifest ./honeypot-artifacts/manifest.json \
  --output ./addresses-for-watch-list.json
```

This will produce a JSON file containing the public addresses for all supported chains (BTC, ETH, SOL, etc.).

## Setting Up Watchlists

We recommend importing these addresses into popular block explorer "Watchlist" or "Address Alert" services. These services will send you an email or webhook notification the moment any activity is detected.

### Ethereum & EVM Chains (Etherscan, Polygonscan, etc.)
1. Create a free account on [Etherscan](https://etherscan.io/).
2. Navigate to **My Account** -> **Watch List**.
3. Click **Add** and paste an exported ETH address.
4. Set the "Notification Method" to "Notify on Incoming & Outgoing Txns".

### Bitcoin (Blockchain.com, Blockonomics)
1. Use a service like [Blockonomics](https://www.blockonomics.co/) or [Blockchain.com](https://www.blockchain.com/explorer).
2. Add your exported BTC addresses to their wallet monitoring/alert tools.

### Solana (Solscan)
1. Go to [Solscan](https://solscan.io/).
2. Use their "Monitor" or "Alert" features (often requires an account) to track the exported SOL addresses.

## Interpreting On-Chain Alerts

| Activity | Severity | Interpretation |
|----------|----------|----------------|
| **Incoming Transfer** | Medium | An attacker might be sending a small amount of gas (dusting) to the address to test if it's active before attempting to sweep it. |
| **Balance Query** | N/A | Hard to detect on public explorers, but often precedes a transfer. |
| **Outgoing Transfer** | Critical | **Confirmed Compromise.** An attacker has successfully stolen the private key and is moving funds. Since these are honeypot addresses, any outgoing transaction is unauthorized. |

## Automated Monitoring (Advanced)

For larger deployments, you may want to automate monitoring using a script or a dedicated service like **Tenderly** (for EVM) or **Alchemy Webhooks**.

You can write a simple Python script using `web3.py` (for ETH) or `solana-py` (for SOL) that polls the balance of your exported addresses and sends an alert to Wazuh via the custom logs API if the balance changes.
