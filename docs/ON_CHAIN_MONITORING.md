# On-Chain Monitoring Guide

This document explains how to set up real-time monitoring for the blockchain addresses generated by the Crypto Wallet Honeypot system.

## Overview

Layer 4 of the honeypot detection strategy involves monitoring the public addresses associated with the honeypot's private keys. If an attacker steals a private key or seed phrase, they will likely import it into a wallet and check the balance or attempt to transfer funds.

By monitoring these addresses on-chain, you can detect the compromise even if the attacker has already exfiltrated the data and left the monitored host.

## 1. Export Honeypot Addresses

Use the `honeypot-deployer` CLI to export all generated addresses from your manifest:

```bash
honeypot-deployer export-addresses \
  --manifest ./my-artifacts/manifest.json \
  --output ./monitored-addresses.json
```

This will create a JSON file containing all addresses organized by chain (BTC, ETH, SOL, etc.).

## 2. Set Up Watchlists

You can monitor these addresses using various blockchain explorer services. Most major explorers offer "Watchlist" or "Address Alert" features.

### Ethereum (ETH/EVM)
- **Service:** [Etherscan](https://etherscan.io/)
- **Setup:** Create a free account, go to the "Watch List" section, and add your honeypot addresses. Enable email notifications for any incoming or outgoing transactions.

### Bitcoin (BTC)
- **Service:** [Blockchain.com Explorer](https://www.blockchain.com/explorer) or [Mempool.space](https://mempool.space/)
- **Setup:** Many Bitcoin explorers allow you to track addresses. For enterprise environments, consider running a `bitcoind` node with `watchonly` addresses.

### Solana (SOL)
- **Service:** [Solscan](https://solscan.io/) or [SolanaFM](https://solana.fm/)
- **Setup:** Use their alert systems to monitor for any account activity or token transfers.

## 3. Integration with Wazuh (Advanced)

For a fully integrated security operations workflow, you can use the `chain-monitor` service (coming soon) to ingest blockchain events directly into Wazuh.

1. The `chain-monitor` daemon polls the blockchain for activity on your exported addresses.
2. When activity is detected, it generates a JSON log entry.
3. The Wazuh agent on the monitoring host reads this log and sends it to the Wazuh Manager.
4. Wazuh Rule ID `100530` (or higher) triggers a critical alert in your dashboard.

## 4. Security Warning

**NEVER deposit real funds into honeypot addresses.** These addresses are designed to be "bait." If funds are present, an attacker will successfully steal them. The goal is to detect the *attempt* or the *query*, not to provide a financial reward to the attacker.
